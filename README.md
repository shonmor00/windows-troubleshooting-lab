# windows-troubleshooting-lab

## Project Overview 
This project documents hands-on IT support exercises using a Windows laptop. The goal is to develop foundations skills in system identification, Windows troubleshooting, diagnostic tools, and technical documentation.

## Lab 1: System Identification

### Objective
Identify and document the laptop's operating system, processor, memory, and manufacturer using the Windows System Information utility.

### Tools Used
- Windows System Information (msinfo32)

- ### System Specifications
  | Component | Specification |
  |---| ---|
  | Operating System | Windows 10 |
  | Processor| Intel Core i5-1035G1 |
  | CPU Core | 4 |
  | Logical Processors | 8 |
  | Reported CPU Speed | 1.19 GHz |
  | Installed RAM | 8 GB |
  | Manufacturer | Microsoft Corporation |

  ### Procedure
  1. Pressed Windows + R to open the Run dialog.
  2. Entered 'msinfo32'.
  3. Opened the System Information utility.
  4. Reviewed the system summary.
  5. Recorded the hardware and operating system specifications.
 
  ### Findings
  Successfully located and documented the laptop's system specifications using a built-in Windows diagnostic utility.

  ### Skills Practiced 
  - Navigating Windows system utilities
  - Identifying hardware specifications
  - Understanding CPU cores and logical processors
  - Reviewing installed memory
  - Technical documentation
 
  ### Next Steps
  - Practice Command Prompt diagnostic commands.
  - Check network connectivity.
  -  Review system performance and running processes.
  -  Document troubleshooting scenarios.
